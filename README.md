# To-Do App

A simple task manager for creating and organizing to-dos. Add tasks, track their completion, edit or remove them, and filter the list by status.

## Live Preview

[Open the live website](https://pwcupcake228-png.github.io/To-Do-App/)

## Technologies

- React 18
- TypeScript
- Vite
- SCSS
- Bulma
- Font Awesome
- REST API for todo data


### Prerequisites

- Node.js 20 or later
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/pwcupcake228-png/To-Do-App.git
   cd To-Do-App
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm start
   ```

The app will be available at the local URL printed in the terminal.

To create a production build, run:

```bash
npm run build
```

## Features

- Create and delete tasks
- Mark tasks as complete or active
- Edit task titles
- Toggle all tasks at once
- Filter tasks by all, active, or completed status
- Clear completed tasks
- Display loading states and error notifications for API operations
